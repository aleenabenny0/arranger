Common questions

My file will not import

Arranger reads standard MIDI files and MusicXML (.musicxml, .xml, .mxl). MIDI files that use SMPTE timecode are not supported: export again with a ticks-per-beat time base. Files with no pitched notes cannot be arranged.

The wrong line was chosen as the melody

Open the piece, go to the Source step, choose the part that carries the tune, and save. Then arrange again.

The arrangement is slower than the original

When a passage moves faster than the hand speed you entered, Arranger keeps every melody note and suggests a slower tempo instead of dropping notes. Raise the hand travel speed in step 2 if it is too cautious for you.

There is no PDF button

PDF engraving needs LilyPond on the server. If it is not installed, MIDI and MusicXML downloads still work, and any notation program can print the MusicXML.

The transcription of my recording is wrong

Transcription works best on a single, clearly recorded instrument. Dense chords, pedal, reverb, singing and drums all make it worse. Remove wrong notes in the Source step before arranging.

Accessibility

Arranger is built to be used with a keyboard and a screen reader, and findings in the score are always listed as text as well. If something does not work for you, please say so using the contact above.
